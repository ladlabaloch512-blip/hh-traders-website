# H.H Traders - Final Website (client reference design)

Static store built to the client's reference design: red/black/white, top bar, search header,
red category nav, hero slider, category tiles, featured products, trust strip, about + why-choose-us.

## Run
Open `index.html` in a browser, or serve the folder: `python3 -m http.server`
Works on GitHub Pages and any static host. All paths are relative.

## Pages
index.html (home), shop.html (filters + category dropdown), product.html?id=N,
cart.html, checkout.html, confirmation.html, 404.html

## Edit
All products, prices, categories and store details live in `data.js`.
Cart and wishlist are saved in the browser (localStorage). Demo design: sample
products and prices for design approval only.
